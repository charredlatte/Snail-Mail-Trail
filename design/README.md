## Getting these into Figma

Drag the `.svg` files onto a Figma canvas, or **File → Import**. Each becomes a
frame with editable layers.

What survives the import:

- **Text stays text.** Every label is a real `<text>` node, so you can retype
  and restyle it rather than tracing over a picture.
- **Layers are grouped and named** — `header`, `filters`, `club-cards`,
  `results-toolbar` and so on, so the layer panel is navigable from the start.
- Shapes import as editable vectors.

What does **not** survive, and is yours to add:

- **Auto-layout.** Everything imports at absolute coordinates. The filter rail
  and the card grid are the two places worth converting first.
- **Components.** The club card repeats twelve times on the search page and
  again in map mode — make it a component once and the rest follow.
- **Text styles and colour variables.** The palette below is applied as flat
  hex values.

Fonts are specified as `Inter, Helvetica, Arial, sans-serif`. Figma substitutes
whatever is available; if you want Inter exactly, install it first and the
import will match.

## These are wireframes, not a visual design

Deliberately grey. They settle **layout, hierarchy and what each screen
contains** — not colour, typography, photography or personality. The brand
pass comes after you have decided the structure is right, and it is much
cheaper to move a filter rail now than after it is built.

## The orange text is not part of the design

Small orange labels like `min_price / max_price (US cents)` and
`GET /api/clubs?q=` map each control to the API field behind it. They are
annotations for whoever builds this — **delete that layer before any visual
design work.**

## Decisions baked into these screens

A few things in here are load-bearing rather than decorative:

- **Prices show twice.** The club's real price (`GBP 14.00 / month`) and the
  comparable figure (`~ $18.48/mo in USD`). The filter compares the second one,
  so hiding it makes the results look wrong to anyone checking the maths.
- **The price filter is labelled "per month" and "USD"** because that is what it
  actually does. A slider labelled just "price" would be a lie across clubs that
  bill yearly in yen.
- **The map is a toggle, never a shrunken sidebar on mobile.** A 390px-wide map
  with pins on it is unusable.
- **The submit form has no latitude/longitude fields.** Coordinates are
  geocoded from the city during import and review.
- **The moderation queue flags foreign-currency listings with no exchange
  rate** (`needs rate`). Approving one in that state prices it as dollars. This
  is the single easiest way for bad data to reach the public directory.
- **Club detail is one URL per club** (`/clubs/columbus-postcard-swap`),
  server-rendered. That page is what ranks in search; it is the whole traffic
  model for a directory.

## Regenerating

These were generated by a script rather than drawn, so the six screens share one
set of components. That script is not kept in the repo — once you start editing
in Figma, Figma is the source of truth and a generator that silently disagrees
with it is worse than no generator. Edit the SVGs or the Figma file directly.
